# Grand Line Çarkı 🏴‍☠️

Şeytan meyveni, kılıcını, Hakini, istatistiklerini ve tayfanı çarkla belirlediğin, sonra toplam güce göre oranlanmış bir çarkla savaştığın hayran yapımı bir çark oyunu.

- **Tek oyunculu:** Zorluk seç (Kolay → Efsane), rakibin o seviyedeki karakterlerden rastgele gelsin.
- **Çok oyunculu:** 2–6 kişi, telefon elden ele dolaşır.

Tek dosyalık statik bir sayfa (`index.html`), kurulum gerekmez.

> Hayran yapımıdır; One Piece ve karakterleri Eiichiro Oda / Shueisha / Toei Animation'a aittir.
